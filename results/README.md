# Каталог результатов

Сохраняйте сюда текстовые отчёты анализаторов согласно инструкции в корневом README.md.

- `static_before` — Pylint, Ruff и Bandit для `original`;
- `static_after` — те же инструменты для `static_defects`;
- `dynamic_before` — cProfile и tracemalloc для `original`;
- `dynamic_after` — те же инструменты для `dynamic_defects`.

Не удаляйте исходный вывод инструментов: он потребуется для итогового отчёта.
